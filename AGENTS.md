# Silent Space Cafe standing design rule

The user requires the homepage header and footer to remain consistent across the customer-facing site, now and in all future work.

- Use `templates/base.html` as the shared layout for every customer page, including menu, booking, story, spaces, bag, checkout, receipt and reservation status pages.
- Preserve the homepage header: warm ivory background, espresso wordmark and navigation, live bag count/icon, and the olive Reserve a seat button. Preserve its typography, spacing, responsive navigation and keyboard behavior.
- Preserve the homepage's shared espresso footer, its styling and useful links.
- Do not introduce page-specific header/footer colours, fonts, dimensions, markup variants or mobile overrides. Mockups guide page content only; their different header/footer styling must not override this standing rule.
- Keep current-page navigation semantics and the live bag count working. Make any approved future header/footer change once in the shared layout/styles so it applies consistently everywhere.
